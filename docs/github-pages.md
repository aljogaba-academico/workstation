# GitHub Pages

## Sitio publicado

https://aljogaba-academico.github.io/workstation/

## Configuración

- Repository: `aljogaba-academico/workstation`
- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`
- HTTPS: enabled

## Mermaid

Mermaid se carga desde jsDelivr mediante un módulo ES. Los diagramas requieren conexión a internet para renderizarse.

## Despliegue

Cada cambio enviado a `main` es publicado por GitHub Pages. Puede existir un breve retraso entre el commit y la actualización del sitio.

## Seguridad

El sitio es público. No publicar:

- tokens;
- variables `.env`;
- credenciales;
- URLs administrativas privadas;
- identificadores sensibles;
- documentación reservada.

La workstation puede representar sistemas privados como nodos conceptuales sin publicar su ubicación ni sus secretos.
